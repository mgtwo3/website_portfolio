# Mark Gillespie — Portfolio

A static, responsive portfolio for GitHub Pages. No build tools or dependencies are required.

## Pages

- `index.html`: homepage and category overview
- `ai-automation.html`: metadata publishing, video QC, and Runway prototype
- `data-analytics.html`: three Tableau dashboards and six SQL studies
- `video-production.html`: news production and four League of Legends videos
- `broadcast-engineering.html`: TYT technical directing and studio work

Shared presentation lives in `styles.css`. Each HTML file contains its full content and works without JavaScript. Screenshots open at full size; external project links open in a new tab.

## Publish to the existing GitHub Pages site

Upload the contents of this folder directly into the root of `mgtwo3/website_portfolio` on the branch used by GitHub Pages. Replace matching files. Do not upload the ZIP itself or nest the files in another folder.

Keep `CNAME` as `www.markgillespie.tech`. Existing GitHub Pages and domain settings do not need to change.

## Content notes

The Runway project is labeled as a prototype. SQL examples are linked to their original source files. No performance metrics, client affiliations, or unconfirmed production roles have been added. GitHub is the provided contact/profile link; add verified email, LinkedIn, and a resume file when available.

The original Tableau screenshots are preserved. Their displayed data and chart formatting have not been altered.
